# hi, i'm noah!

i'm a senior engineer on the Web Platform team at [Airbnb](https://airbnb.tech/). before that, i spent six and a half years at [Meta](https://engineering.fb.com) working on [React](https://react.dev) and web infrastructure, with a batch at the [Recurse Center](https://www.recurse.com/) in between.

## open source highlights

- **[React](https://github.com/facebook/react)** · former core team member. coordinated a company-wide deprecation of legacy APIs via codemods and instrumentation — migrated 6,500+ callsites and unblocked [open-source React development](https://github.com/facebook/react/pulls?q=is%3Apr+author%3Anoahlemen+is%3Amerged). integrated [`scheduler.yield`](https://github.com/facebook/react/pull/27069) into React's [`postTask`](https://github.com/facebook/react/pull/27295) scheduler, ran the experiments that [retired `isInputPending`](https://github.com/facebook/react/pull/28444), and investigated [Activity](https://react.dev/reference/react/Activity) compatibility ahead of its stable release.

- **Chromium & web standards** · removed unload handlers from Facebook's pixel — one of the most widely deployed scripts on the web — resolving the web's #1 source of [back/forward cache](https://web.dev/articles/bfcache) ineligibility. proposed and implemented the [Service Worker Subresource Filter](https://chromestatus.com/feature/6015753541124096) ([spec proposal](https://github.com/w3c/ServiceWorker/issues/1584)), running its origin trial on facebook.com; Chrome 123 later shipped the [Static Routing API](https://developer.chrome.com/blog/service-worker-static-routing) to generalize it. ran [content-visibility](https://web.dev/articles/content-visibility) on facebook.com at scale, uncovering the bugs that blocked its use at that scale.

- **[flow-api-translator](https://github.com/facebook/hermes/tree/main/tools/hermes-parser/js/flow-api-translator)** · took this from prototype to production with the Flow team ([commits](https://github.com/search?q=repo%3Afacebook%2Fhermes+%22noahlemen%40meta.com%22&type=commits)). translates Flow source into `.d.ts` and plain JS for TypeScript interop. adopted in [StyleX](https://github.com/facebook/stylex), [Metro](https://github.com/facebook/metro), Messenger Desktop, and React Native, where it powers [RN 0.80's strict TypeScript API](https://reactnative.dev/blog/2025/06/12/moving-towards-a-stable-javascript-api).
